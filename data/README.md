# Dữ liệu

Các notebook hiện dùng dữ liệu nhỏ được tạo trực tiếp và seed `42`, nên repository không cần tải dataset bên ngoài.

Nếu bổ sung dataset:

- Dữ liệu nhỏ, được phép phân phối: đặt trong `data/raw/` và ghi nguồn/license.
- Dữ liệu đã xử lý: đặt trong `data/processed/` và cung cấp script tái tạo.
- Dữ liệu lớn hoặc nhạy cảm: không commit; ghi hướng dẫn tải và checksum tại đây.
